# bryand410.github.io

Personal portfolio — DevSecOps & cybersecurity engineer.

Single `index.html`. No framework, no build step, no bundler. The only external
request is the Google Fonts stylesheet.

- Bilingual FR/EN, toggled client-side and remembered in `localStorage`
- Dark and light theme, following the OS preference by default
- Motion: scroll-reveal with stagger, animated ambient background, count-up
  statistics, pointer-tracked card spotlight, scroll progress bar
- All animation is disabled under `prefers-reduced-motion`
- Content is limited to what can be verified: the two Oracle certificate IDs,
  the llm-sentinel benchmark including its documented failures, and the two
  roles with their actual date ranges
