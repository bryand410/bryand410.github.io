llm-sentinel Open source · MIT

AI security gateway — Python, PyTorch, FastAPI, Docker Passerelle de sécurité IA — Python, PyTorch, FastAPI, Docker

A guardrail that classifies a prompt as safe or injection before it reaches the model. Most guardrails are either a regex list or an API call to someone else's cloud; this one is a small fine-tuned transformer that runs entirely on your own machine, on CPU — which is the point when the text you are screening is the text you were trying not to leak. Un garde-fou qui classe un prompt en sûr ou injection avant qu'il n'atteigne le modèle. La plupart des garde-fous sont soit une liste de regex, soit un appel à l'API cloud d'un tiers ; celui-ci est un petit transformer fine-tuné qui tourne entièrement sur ta machine, sur CPU — ce qui est tout l'intérêt quand le texte que tu filtres est celui que tu cherchais à ne pas laisser fuiter.

  • Fine-tuned 4.4M-parameter encoder (bert-tiny), binary sequence classificationEncodeur de 4,4 M de paramètres fine-tuné (bert-tiny), classification binaire
  • Under 50 ms per request on CPUMoins de 50 ms par requête sur CPU
  • Trained on deepset/prompt-injections plus hand-written bilingual FR/EN casesEntraîné sur deepset/prompt-injections plus des cas bilingues FR/EN écrits à la main
  • 88.6% on its own 35-case bench — including the four cases it gets wrong, which are documented88,6 % sur son propre banc de 35 cas — y compris les quatre cas qu'il rate, qui sont documentés
  • FastAPI service, dashboard, pytest suite, GitHub Actions CI (lint, tests, Docker build)Service FastAPI, dashboard, suite pytest, CI GitHub Actions (lint, tests, build Docker)
